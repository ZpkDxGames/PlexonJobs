# PlexonJobs 1.0.0 stable release gates

Repository/CI evidence can prove build, tests, distribution shape, Core API compatibility and deterministic payout-unit behavior.

The following require live server or staging evidence and **must not be invented**:

- Vault provider integration against the production provider.
- Migration dry-run and execute from the administrator's actual Jobs data.
- SHADOW comparison of hourly money and XP.
- PRIMARY staging.
- Economy balance review against the live shop/rank economy.
- Spark A/B comparison.
- 1/5/10-player mining runs.
- Hunter and Builder abuse tests after their Core contexts exist.
- Vault outage/recovery against the live provider.
- Shutdown payout behavior against the live provider.
- 30-minute mixed soak.
- Legacy Jobs decommission verification.

Until those are supplied, the repository is **CANDIDATE READY**, not stable `v1.0.0`.
